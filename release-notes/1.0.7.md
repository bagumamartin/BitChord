# BitChord 1.0.7

## Automix

- Transitions are calmer on the CPU. Track analysis is paced so it no longer piles up with playback resolution, and each track is decoded once for analysis.
- Less memory during transitions. The Neural Engine beat model has a new version (v2) that holds about 370 MB less, and it is released shortly after use instead of lingering. Peaks drop from about 1.1 GB to about 700 MB.
- Installed Automix models update themselves when a newer version is pinned; the old one keeps working until the new one is verified. With Wi-Fi-only downloads on, a metered connection still waits for Wi-Fi.

## Lyrics

- Untimed lyrics are aligned against the whole song, including songs in several languages and scripts without spaces.
- Lyrics on Player can be turned off in Settings.

## Playback

- Songs start faster after launch: the prepared YouTube player is cached on disk.
- The playing-row bars and the title marquee use far less CPU, especially on Mac.
