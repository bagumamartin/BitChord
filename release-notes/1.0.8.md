# BitChord 1.0.8

## Playback

- Fixes "Couldn't open a stream for that track" and "confirm you're not a bot" on networks where other YouTube clients still play. BitChord kept presenting the same YouTube identity once it had been flagged, so no retry, network or account could clear it. Each track is now asked for with a fresh anonymous identity, the way the working clients ask, and YouTube cookies are no longer stored.
- The YouTube extractor is updated to InnerTubeX 0.11.6.
- A track that fails is no longer asked for again in quick bursts, which could make a flagged network worse.
- Diagnostic reports now say which YouTube client refused a track and why.

## Security

- rustls 0.23.46.
